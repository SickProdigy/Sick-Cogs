# Avatar

Avatar is a small Red-DiscordBot cog for returning a Discord user's avatar URL.

The command defaults to the user who runs it, and accepts a member mention, username, nickname, or user ID when checking someone else.

## Commands

- `[p]avatar` - Show your avatar URL.
- `[p]avatar <user>` - Show another user's avatar URL.

This cog does not store user data.
