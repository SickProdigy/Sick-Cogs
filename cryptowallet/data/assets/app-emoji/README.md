# CryptoWallet network emoji assets

These files are ready to upload as Discord application emojis. Each image is a
128 × 128 transparent PNG and is below Discord's 256 KB upload limit. Keep the
filename stem as the emoji name:

| File | Emoji name | Wallet network |
| --- | --- | --- |
| `base.png` | `base` | Base Sepolia |
| `ethereum.png` | `ethereum` | Ethereum Sepolia |
| `arbitrum.png` | `arbitrum` | Arbitrum Sepolia |
| `polygon.png` | `polygon` | Polygon Amoy |
| `avalanche.png` | `avalanche` | Avalanche Fuji |
| `solana.png` | `solana` | Solana Devnet |
| `optimism.png` | `optimism` | Optimism (future; disabled) |
| `bnb.png` | `bnb` | BNB Chain (future; disabled) |
| `zora.png` | `zora` | Zora (future; disabled) |
| `tron.png` | `tron` | TRON (future; disabled) |
| `linea.png` | `linea` | Linea (future; disabled) |

All images except `zora.png` were normalized from the corresponding chain images in
[Trust Wallet Assets](https://github.com/trustwallet/assets), which is distributed
under the MIT License. `zora.png` was normalized from the official
[Zora GitHub organization](https://github.com/ourzora) avatar. The underlying names and marks remain the property of their
respective owners. Their inclusion identifies supported networks and does not imply
sponsorship or endorsement.
