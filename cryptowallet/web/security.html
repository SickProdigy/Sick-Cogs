Security and permissions

Wallet security controls are managed from Discord so the bot can enforce them before any provider operation.

If your Discord account may be compromised

Run !wallet security lock as soon as possible or ask the bot owner to run !walletset lock @username or use your numeric Discord user ID. A lock blocks new sends, authorization, renewal, and signer export while leaving deposits and read-only wallet information available. Only the bot owner can unlock it after identity review.

Authorization revocation remains available while locked. Independent 2FA is not enabled yet, and mainnet remains disabled.
