# Pokemon

Experimental global Pokémon catching and wild-battle cog.

## Current prototype

- Global collection per Discord user across every guild served by this bot instance.
- Bulbasaur, Charmander, or Squirtle starter.
- Twelve-species Kanto catalog and activity-driven wild spawns.
- Administrator-approved spawn channels only.
- Exclusive persistent encounters with two-move battles.
- Poké Ball catches, parties up to six, and collection display.
- Front/back sprite presentation through a replaceable URL helper.

Separate bot installations do not share collections.

## Setup

1. Load the cog.
2. Enable a channel with `[p]pokemon set channel #channel`.
3. Members choose with `[p]pokemon starter bulbasaur|charmander|squirtle`.
4. Meaningful conversation eventually triggers a wild encounter.
5. Press **Encounter**, battle, and throw a Poké Ball.

This unofficial noncommercial prototype supports only its bundled species and mechanics. PvP, trading, leveling, evolution, composite battle images, items beyond Poké Balls, and a full Pokédex are deferred.
