# MTG visual assets

`default_playmat.png` is an original background generated for Sick-Cogs with OpenAI's built-in image generation tool. It contains no card faces, game logos, trademarks, or text.

Final generation prompt:

> Create an original top-down fantasy card-table playmat background for a two-player strategy card game. Use a symmetrical landscape composition with quiet top and bottom player zones, a central combat lane, muted charcoal, forest green, burgundy, and gold, and subtle cloth/stone texture. Keep broad negative space for programmatic overlays. Include no cards, card backs, creatures, characters, text, numbers, logos, trademarks, recognizable game symbols, or watermarks.

Card artwork is not bundled here. The cog retrieves supported printing images from Scryfall at runtime and stores them in its bounded private cache.
