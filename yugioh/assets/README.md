# Original interface assets

duel_table.png, hand_tray.png, and card_back.png were generated for Sick-Cogs with OpenAI image generation on 2026-10-05.

Prompts requested an original charcoal, gunmetal, blue-violet, and amber techno-occult interface with no text, logos, trademarks, characters, official card faces, or copied anime Duel Disk design. duel_table.png is the public top-down playmat, hand_tray.png is the private hand composition, and card_back.png represents every hidden card.

These files are interface backgrounds only. Official card images are never bundled and are cached privately at runtime.
