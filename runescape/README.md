# RuneScape

Look up Old School RuneScape and RuneScape players, items, quests, and wiki articles
from Discord.

## Usage

No API key is required. The cog sends player names and search terms to Jagex hiscores
and the official RuneScape wiki services.

```text
[p]rs user <username>
[p]rs wiki <query>
[p]rs rs3wiki <query>
[p]rs item <item name>
[p]rs quest <quest name>
```

Replace `[p]` with the bot's configured prefix. Use `[p]help rs` and its subcommands
for the complete syntax.

The lookup commands return embeds and interactive wiki search results, so the bot needs
permission to send messages and embed links in the invoking channel.

## Data

This cog does not persistently store user data or metadata.
